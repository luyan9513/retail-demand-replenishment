# 简历 Bullet

1. 基于 UCI Online Retail II 的 **1,067,371** 条公开交易记录，使用 DuckDB + dbt 构建销售额 Top 30 SKU 的 SKU×日需求数据集，完成取消、数量/价格异常、候选重复、缺失和长尾的 **11 项**可复现质量审计。
2. 设计“默认保留候选重复 + 严格去重对照”的数据口径，并量化其对行数、销量、销售额的影响（严格口径少 **215,157** 件销量、**496,334.10** 销售额），避免无订单行 ID 时过度清洗。
3. 采用 3 个滚动 7 天时间窗口比较 seasonal naive、移动平均、Croston-SBA 与共享 HistGradientBoosting，在 **25** 个完整回测 SKU 的 567 个公平观测上，HGB 达到 WAPE **0.7534**、MAE **71.74**；保留其 sMAPE 非最优的限制。
4. 基于价值、波动、非零天占比和间歇性分层并逐 SKU 选模（HGB 12、移动平均 10、seasonal naive 3），将回测与未来预测统一为同一共享 HGB 路径，并用端到端测试保护短历史边界。
5. 构建含库存位置、提前期波动、服务水平、MOQ、箱规和成本代理的安全库存/ROP 情景模拟与 Streamlit 看板；明确标注为公开数据下的参数化复核工具，不宣称真实库存优化或经营收益。
