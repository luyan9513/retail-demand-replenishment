# 简历 Bullet

1. 基于 UCI Online Retail II 的 **1,067,371** 条公开交易记录，构建销售额 Top 30 SKU 的 SKU×日需求数据集，并完成取消单、异常数量/价格、候选重复记录与长尾商品的数据质量审计。
2. 采用 3 个滚动时间窗口比较 seasonal naive、移动平均与 HistGradientBoosting，在 **25** 个完成完整回测的 SKU 上评估 7 天需求预测；HGB 总体 WAPE 为 **0.7316**、MAE 为 **69.05**。
3. 基于销售额、需求波动、非零天占比和间歇性对 30 个高价值 SKU 分层，输出稳定、周期、高波动和间歇/长尾需求的差异化选模；15 个 SKU 选择 HGB、8 个选择移动平均、2 个选择 seasonal naive。
4. 在公开数据缺少真实库存与采购信息的前提下，构建可配置提前期、服务水平和假设库存的安全库存/补货点情景模拟工具，为 25 个 SKU 输出可追溯的理论补货缺口。
5. 构建提前期、服务水平、库存、持有成本与缺货成本的敏感性分析，比较建议补货总量与高风险 SKU 覆盖变化；结论明确为公开数据下的参数化模拟，不代表真实经营收益。
