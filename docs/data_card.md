# 数据卡｜UCI Online Retail II

## 基本信息

- 数据集：Online Retail II（UCI Machine Learning Repository）。
- 访问地址：https://archive-beta.ics.uci.edu/dataset/502/online%2Bretail%2Bii
- 许可：CC BY 4.0；项目发布时保留 UCI、数据集名称、链接及许可链接。
- 计划用途：从交易行构造 SKU×日的正向销售需求代理。

## 数据粒度与字段

预期为一条交易行，包含发票、SKU、描述、数量、交易时间、单价、客户和国家。`src/ingest.py` 将字段标准化为 `invoice_no`、`stock_code`、`quantity`、`invoice_date`、`unit_price` 等，并为每行添加 `source_row_number`。

## 适用性与局限

适合：分析历史成交销量、周内节奏、销售价值和退货/取消信号。

不适合直接回答：真实库存、补货执行、在途、供应提前期分布、缺货未满足需求、促销因果效果、采购成本、毛利和利润。故本项目把交易销量作为需求代理，补货模块为模拟。

## 处理记录

取消单以发票前缀 C 标记；数量/单价非正、缺 SKU、缺日期和候选重复行在审计中保留。默认正向销量使用非取消、数量与单价为正、SKU/日期非空的行，**不因候选重复自动删除**；另有严格去重对照，只保留候选键排名第一的行。

## 实际运行快照（2026-08-01）

- 下载文件：UCI 官方 `online_retail_II.zip`（43.5 MB），SHA-256 为 `572e36277c2390fbfde10664750731e0a86f55e33470d91919085f0408e67bfb`。
- 导入范围：两张年度工作表，1,067,371 行；销售额 Top 30 SKU 的日级主题表覆盖 2009-12-01 至 2011-12-09，共 19,772 个 SKU×日记录。
- 审计：19,494 个取消单行（1.83%）；22,950 行数量异常；6,207 行价格异常；34,335 行候选业务重复；缺 SKU 与缺日期均为 0；3,135 个 SKU 的非零天占比低于 30%。
- 默认有效正向销售行：1,041,670；严格候选去重对照：1,007,913。两者相差 33,757 行、215,157 件销量和 496,334.10 销售额；候选重复仍需在真实业务中结合订单行号确认，不能自动等同于系统重复录入。
